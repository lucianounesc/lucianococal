🚀 Missão 1 — Conhecendo a linguagem C

Imagine que você precisa ensinar um computador a fazer alguma coisa. Para isso, precisamos escrever instruções que ele consiga entender.

💡 Curiosidade: C é uma linguagem muito importante na história da computação e ainda é utilizada em muitos projetos.

Seu primeiro programa

#include <stdio.h>

int main() {
    printf("Olá, mundo!");
    return 0;
}

O comando printf() mostra uma mensagem na tela.

🧩 Desafio

Modifique o programa para mostrar seu nome na tela.

#include <stdio.h>

int main() {
    printf("Meu nome é Ana!");
    return 0;
}

📦 Missão 2 — As caixas mágicas: variáveis

Uma variável é como uma caixa onde podemos guardar uma informação.

📦 int
guarda números inteiros
📦 float
guarda números com casas decimais
📦 char
guarda um caractere
📦 char[]
pode representar um texto
int idade = 14;
float altura = 1.65;
char letra = 'A';

printf("%d\n", idade);
printf("%.2f\n", altura);
printf("%c\n", letra);
🎮 Pense em um jogo: podemos ter uma variável chamada pontos para guardar a pontuação do jogador.

🧩 Desafio

Crie uma variável chamada pontos, coloque o valor 100 nela e mostre o valor na tela.

int pontos = 100;
printf("%d", pontos);

⌨️ Missão 3 — Conversando com o computador

Até agora o programa só falava conosco. Agora vamos fazer o computador receber informações.

📢 printf() — computador fala

printf("Qual é a sua idade?");

👂 scanf() — computador escuta

int idade;

printf("Digite sua idade: ");
scanf("%d", &idade);

printf("Você tem %d anos!", idade);
🎤 Imagine assim: printf() é o computador falando e scanf() é o computador ouvindo.

🧩 Desafio

Faça um programa que pergunte o nome e a idade do jogador.

#include <stdio.h>

int main() {
    char nome[30];
    int idade;

    printf("Digite seu nome: ");
    scanf("%29s", nome);

    printf("Digite sua idade: ");
    scanf("%d", &idade);

    printf("Olá, %s! Você tem %d anos.", nome, idade);

    return 0;
}

🤔 Missão 4 — O computador precisa tomar decisões

Programas podem tomar decisões usando condições.

Exemplo: se a pontuação for maior ou igual a 100, o jogador ganhou um prêmio. Caso contrário, precisa continuar jogando.
if (pontos >= 100) {
    printf("🏆 Você ganhou!");
} else {
    printf("Continue tentando!");
}

⚖️ Comparações

== igual
!= diferente
> maior
< menor
>= maior ou igual
<= menor ou igual

🧩 Desafio

Leia a idade de uma pessoa e informe se ela pode votar ou ainda não tem idade para votar. (Considere 16 anos como idade mínima para este exercício.)

int idade;

scanf("%d", &idade);

if (idade >= 16) {
    printf("Pode votar.");
} else {
    printf("Ainda não pode votar.");
}

🔄 Missão 5 — Fazendo o computador repetir

Imagine pedir para alguém escrever os números de 1 até 100. Seria muito cansativo fazer isso manualmente! Com uma repetição, o computador faz o trabalho.

🔁 for

for (int i = 1; i <= 10; i++) {
    printf("%d\n", i);
}

O programa começa em 1, continua enquanto i <= 10 e aumenta 1 a cada repetição.

🔁 while

int contador = 1;

while (contador <= 5) {
    printf("%d\n", contador);
    contador++;
}
🎮 Desafio de jogo: você pode usar uma repetição para mostrar várias fases, contar pontos ou repetir uma pergunta.

🧩 Desafio

Mostre na tela os números de 1 até 20 usando for.

for (int i = 1; i <= 20; i++) {
    printf("%d\n", i);
}
